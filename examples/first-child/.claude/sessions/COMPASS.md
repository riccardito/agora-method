# Agora Compass — units

The durable layer above the session files. `/agora --start` reads it every session.

## Vision

Unit conversion that is exact, explainable and boring: every answer can say which
definition it used.

## Mission

(Opened 2026-01-05.) A converter covering length, mass and volume, published on
PyPI, maintained with the Agora method.

## Eras

### Era: Foundations — the first usable converter  *(current)*

- **Why:** nothing exists yet; the first chapter makes one conversion path work end to end.
- **Goals inside:** Length conversions.
- **When it is finished:** a release a stranger can install and use.

## Goals (active)

### Goal: Length conversions

- **Status:** active — opened 2026-01-05
- **Era:** Foundations
- **Intent:** Convert between metric and imperial lengths with exact factors.
- **Success criteria:**
  - [x] The unit table is data (`units.yaml`), not code
  - [ ] Inches, feet, yards and miles convert to metres and back
  - [ ] Every result names the definition it used
- **Milestone tag:** `milestone-length`
