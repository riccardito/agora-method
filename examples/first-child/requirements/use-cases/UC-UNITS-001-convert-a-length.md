# UC-UNITS-001: Convert a length

## Goal

A user converts a length between metric and imperial units and reads an exact result.

## Main flow

1. The user names a value, its unit and the target unit.
2. The converter applies the defining factors (US-UNITS-001).
3. The result is shown rounded, with the exact value kept.

## Alternative flows

- **An unknown unit:** the converter names the units it knows.
