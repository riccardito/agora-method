# Glossary

Terms a story can cite in `glossary_terms:` (rule C12).

### GLOSS-SESSION

**Session.** One bounded work window with a file of its own: intent, plan, log, close-out and a baton for the next one.

### GLOSS-NOD

**Nod.** A human's explicit approval at a gate, written beside the phase it approves.

### GLOSS-BATON

**Baton.** The short list of what comes next that a closing session hands to the next.

### GLOSS-RATCHET

**Ratchet.** A baseline that may only move one way; growth fails unless named.

### GLOSS-DOMAIN-SHARE

**Domain share.** The share of corpus lines that name the parent product's domain. Published target: 0 %.

### GLOSS-CHECK

**Check.** A script with an exit code that fails the build when a rule is broken.

### GLOSS-CATALOGUE

**Catalogue.** The stories, use cases and quality criteria under `requirements/`, held together by the catalogue check.
